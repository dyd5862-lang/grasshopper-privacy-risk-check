## 새로 확대한 공식 조사

국가법령정보센터 법령MCP `search_decisions(domain=pipc,display=100,page=1..43,sort=ddes)`에서 현재 보고한4253개를 모두 반환받았다. ID4253개가 서로 다르다. 개별 의안번호는 중복될 수 있어 ID수를 실제 사건수로 세지 않는다. `official-law-index-4253.csv.gz`에 실제 반환한ID·제목·번호·의결일·페이지를 보존했다. 압축 전 SHA256은 scope.json에 있다.

이 목록은 **작업일 현재의 공식 서비스 수록 목록**이지 11월1일까지의 PIPC 공개일 전수 목록이 아니다. 공개일 필드가 없고 의결일 정렬도 공개일을 보장하지 않는다. 따라서4253개를 새 공개 의결서4253건 또는 기준일 신규 사건수로 집계하지 않는다.

기존 미확보30개는 전체 목록에서도 정확한 번호 일치를 찾지 못했다. 검색 결과에서 번호/제목이 누락된261개 ID를 `get_decision_text(full=true)`로 각각 조회했다. 응답261개를 확보했으나 사례번호는 null로 남았다. 이유 섹션 유무만으로 전문 확인을 단정하지 않는다.116개는 이유가 ‘별지와 같다’ 형식이며 실제 별지 본문 확인이 필요하고50개 응답에는 이미지 참조가 있다. 30개와 같은 사건이라고 확정할 근거가 없어 기존 연결을 교체·삭제하거나 신규 의안번호를 만들지 않았다. 미일치가 부존재·비공개를 의미하지 않는다.

`unnumbered-records-261.csv`는 회수 범위만 나타낸다. 제목이 없는 자료라도 본문에 특정 사업자가 언급되면 소재 후보로 보존했지만 공식 의안번호·대상 동일성 없이 사례에 연결하지 않았다. 새 전체 원문 확보나 전체 문서검증 완료는0건이다.

## 남은 접근 오류

PIPC 원래 보도자료 첫 목록은1336건/134페이지·최상단1336번 ntt12602·2026-10-29 상태를 반환했다. 실제2페이지 링크는 bbsId가 없는 `selectBoardList.do?pageIndex=2`로 열려 ‘알 수 없는 오류가 발생했습니다’를 반환했다. 원 서버의 게시물 부존재나 HTTP503로 해석하지 않는다.

공식 정책브리핑 기존 목록은 관찰했지만 실제 상세 URL에서 확인한 검색 매개변수의 대상기간9/1~11/1 목록은 웹 도구에서 접근 불가였다. 따라서 기존 부분25개에서 기간 전체 목록 확정으로 전환하지 않았다. 최초 입력 오타가 있는 재게시 목록 URL은 근거에서 제외하고 실제 반환 원본URL을 사용했다.

제이에너텍 텍스트가 제공한 실제 이미지 참조 `https://www.law.go.kr/LSW/flDownload.do?flSeq=169436081`는 웹 도구에서 접근 불가, 일반 파일 다운로드에서HTTP503이었다. 표·이미지 확인 실패를 유지했다. 임의 첨부주소·인증값·세션주소를 만들거나 보안 우회하지 않았다.
