## 1. 비교 범위와 근거

사용자가 제공한 2025년 MD 4,432줄 및 2026년 MD 5,248줄 전체를 비교했다. 고시 전문, 조문별 해설, FAQ, 위험도 분석 해설, 암호화 참고 웹사이트와 별표를 분리해 검토했다. 공백·마크다운·표 구조·페이지 머리말 등 차이를 제외한 문단 대조에서도 텍스트 복원 차이가 다수 확인되었다. 특히 구판 MD는 제1조 해설, 제5조 해설 일부, 제10~13조 해설, FAQ 앞부분과 위험도 분석 개요 등에서 그림 OCR 누락이 크다. **구판 MD에서 추출되지 않은 문장을 새 의무의 신설로 판정하지 않았다. PDF 이미지 자체의 완전한 시각 대조를 완료했다는 의미는 아니다.**

공식 확인 자료:

- [개정이유·주요내용](https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000281400&chrClsCd=010202&urlMode=admRulRvsInfoR)

국가법령정보센터의 공식 전문을 별도 법령 조회 경로로 읽어 제1~19조(제6조의2 포함), 누적 부칙 및 별표를 확인했다. 신규 제18조는 3개 항이며 별도의 호는 없다. 안내서 발간일, 고시 발령일, 조항별 시행일, 서비스 배포일은 별도로 관리한다.

## 6. 검증 및 배포 기록

개별 실행 결과와 실제 배포 식별자는 최종 운영 검증 후 이 보고서의 배포 결과본에 추가한다. 이 커밋의 비교·반영 내역은 배포 전 기록이다. 완료되지 않은 항목을 성공으로 표시하지 않는다.

- 타입 검사·Lint·프로덕션 빌드: 통과(코드 최종 수정 시 재실행).
- 단위·데이터·시행일·마이그레이션 테스트: 65개 통과.
- 실제 Next.js 정적 렌더 결과 테스트: 2개 통과.
- 종전 사례·의결서·보도자료 데이터 보존: 기존 무결성 테스트 통과.
- 운영환경 사용자 동작 및 모바일·데스크톱 검증: 배포 후 확인.
- 공식 안내서 게시물·고시 전문: 확인. 게시물에서 PDF 파일명은 확인했으나 직접 다운로드 URL을 얻지 못해 임의 파일 ID를 생성하지 않았고 공식 PDF 첨부 게시물로 연결한다. PDF 직접 열기·페이지 앵커는 미검증이다.
- 구판 MD의 그림 OCR 누락: 원문 이미지 전체의 신구 시각 대조는 미완료이며 이를 근거로 새 의무를 만들지 않았다.
- 2026-11-01 전 과거 점검: 최신 개정 문항을 현재 의무로 오판하지 않으나 종전 조문별 전체 판정 엔진을 새로 구축한 것은 아니다. 과거 법적 적합성을 완전 자동 확정하지 않는다.
- 다국어: 현재 main에 별도 다국어 전환 구현이 확인되지 않았으며 새 번역 기능을 추가했다고 주장하지 않는다. 기존 코드·읽기설정·사례 데이터는 보존한다.
