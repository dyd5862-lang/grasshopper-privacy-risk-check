# 🦗 메뚜기가 만든 개인정보 위험도 분석 자가 점검 도구

개인정보 보호 실무자가 개인정보 처리 현황과 보호조치 수준을 스스로 점검하고, 관련 법적 근거·안내서·공식 조사·처분 사례와 개선 우선순위를 확인할 수 있도록 만든 웹 기반 자가 점검 도구입니다.

> **중요:** 이 도구에는 실제 개인정보, 비밀번호, 인증정보, 비공개 업무자료 등 민감한 정보를 입력하지 마십시오.

## 서비스

- 운영 주소: https://grasshopper-privacy-risk-check.vercel.app/
- 별도 설치 없이 웹 브라우저에서 사용할 수 있습니다.

## 주요 기능

1. **대상 확인** — 개인정보 처리 현황을 먼저 확인합니다.
2. **보호조치 점검** — 기관 기준 11개 항목, 시스템 기준 15개 항목에 응답하고 증적을 기록합니다.
3. **자동 판정** — 충족, 미흡, 확인 필요, 증적 미확인 등으로 분류합니다.
4. **결과보고서** — 법적 근거와 개선 우선순위를 포함한 결과를 확인·인쇄할 수 있습니다.
5. **실무 참고자료** — 관련 법령, 안내서의 점검 항목·해설, 개인정보보호위원회 공식 조사·처분 사례를 점검 과정에서 참고할 수 있습니다.

## 개인정보 및 데이터 처리

이 프로젝트의 핵심 자가 점검 기능은 사용자가 입력한 점검 상태를 브라우저의 `localStorage`에 저장하도록 구현되어 있습니다. 핵심 자가 점검 기능을 위해 별도의 데이터베이스나 필수 서버 저장소를 사용하지 않습니다.

다만 이 도구는 개인정보를 실제로 처리하기 위한 시스템이 아닙니다. 점검 메모나 증적란에도 실제 개인정보, 주민등록번호, 연락처, 계정정보, 내부 비밀정보 등을 입력하지 마십시오.

브라우저 저장정보는 브라우저·기기 환경에 따라 남아 있을 수 있으므로 공용 PC 사용을 피하고, 사용 후 필요한 경우 도구의 초기화 기능 또는 브라우저 저장정보 삭제 기능을 이용하십시오.

## 법령 및 참고자료

법률·시행령·「개인정보의 안전성 확보조치 기준」 관련 링크는 별도의 법령 API 키 없이 외부 법령 열람 페이지를 새 창으로 열도록 구성되어 있습니다.

수록된 법령·안내서·공식 조사·처분 사례 등의 제목, 요약, 식별정보 및 링크는 실무상 참고 편의를 위한 것입니다. 최신 법령 및 공식 내용은 반드시 해당 법령·공식 원문을 다시 확인하십시오.

## 면책사항

이 도구의 결과는 자가 점검을 지원하기 위한 참고자료이며, 개인정보 보호법 준수 여부에 대한 법률적 판단, 개인정보보호위원회 또는 다른 기관의 공식적인 유권해석·점검·조사·처분 결과를 대신하지 않습니다.

자동 판정 결과만으로 법적 의무의 이행 또는 위반 여부를 확정해서는 안 되며, 실제 업무에서는 최신 법령, 고시, 공식 안내서 및 개별 사안의 사실관계를 함께 검토해야 합니다.

## 로컬 실행

Node.js 22.13 이상을 권장합니다.

```bash
npm ci
npm run dev
```

표준 Next.js App Router 개발 환경으로 실행됩니다.

## Production Build

Vercel과 동일한 Next.js production build를 로컬에서 확인하려면 다음과 같이 실행할 수 있습니다.

```bash
VERCEL=1 npm run build
```

Windows PowerShell:

```powershell
$env:VERCEL="1"; npm run build
```

## Vercel 배포

1. 이 저장소를 자신의 GitHub 계정으로 Fork하거나 복제합니다.
2. Vercel에서 새 프로젝트를 만들고 해당 GitHub 저장소를 선택합니다.
3. Framework Preset이 `Next.js`로 인식되는지 확인합니다.
4. 저장소 루트가 프로젝트 루트라면 Root Directory는 비워 둡니다.
5. Build Command는 `npm run build`를 사용합니다.
6. 배포 전에 자신의 환경과 공개 범위를 다시 확인합니다.

이 공개본에는 원 운영 프로젝트의 `.vercel` 연결정보, `.openai` 호스팅 메타데이터 및 로컬 Production 배포용 스크립트를 포함하지 않습니다.

## 환경변수

현재 핵심 자가 점검 기능, 브라우저 내 상태 저장, 결과 화면 및 법령 연결에는 필수 환경변수가 없습니다. `.env*` 파일은 기본적으로 Git에서 제외됩니다.

비밀키, API 키, 토큰, 계정정보 등을 저장소에 커밋하지 마십시오.

## 프로젝트 구조

- `app/` — 화면, 점검 로직, 사례·의결 데이터
