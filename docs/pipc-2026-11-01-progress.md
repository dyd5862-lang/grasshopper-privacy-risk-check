## 전수 대조 진행과 장애

기존 109개 사례의 고유 출처 URL 108개에 일괄 열람을 요청했다. 88개는 페이지 반환 응답, 20개는 접근 오류였다. 페이지 반환을 본문·법령·문항 연결 검증 완료로 계산하지 않았다. 반환된 일부 응답은 본문까지 포함하지 않거나 과거 수집된 페이지다. 사례별 요청 상태는 pipc-2026-11-01-access-ledger.csv에 기록했다. source_ref는 이번 조사 세션의 조회 식별자이며 영구 원문 주소는 source_url이다.

공식 보도자료 목록의 과거 페이지와 공개 의결서 본문을 확보하지 못했다. 두 공식 호스트의 일반 브라우저 탐색은 연결 시간 초과 화면을 반환했고 직접 HTTP 요청도 503이었다. 따라서 실제 페이지의 href/onclick·폼·다운로드 요청을 관찰할 수 없었다. 보안 차단이나 비공개 상태로 단정하지 않았다. 임의 다운로드 주소·API·세션은 생성하지 않았다.

공식 HTML의 고객센터 사전 실태점검 결과(nttId=12601)도 열람했다. 일부 사업자 익명 표기와 제재 사례 범위·문항 연결을 확정하지 않아 이번 신규 사례에는 포함하지 않았다. 검색으로 찾은 9월 자료만으로 전체 목록을 대체하지 않았다.

관련 결정문 2026-0800·2026-0741·2026-0713의 헤더 범위와 첨부 목록 수를 동일시하지 않는다. 신규 의결서 본문 확인은 0개다. 기존 109개 원문·법령·처분·문항 전체 대조도 미완료다.
