개인정보위 첨부 다운로드 경로를 반복하지 않고 국가법령정보센터의 위원회 결정문 공식 서비스를 법령MCP의 `search_decisions(domain=pipc)`와 `get_decision_text(full=true)`로 조회했다. 검색의 의안번호 키워드는 결과가 없었지만, 사건명 검색 후 **실제 반환된 문서 ID**로 전문을 조회하는 방식이 작동했다. 번호·대상·의결일·주문·법적 판단을 개인정보위 첨부 목록과 대조했다. 비공식 법률 사이트는 원문 소재 탐색만을 위해 사용하고 사실확정 근거로 사용하지 않았다.

## 보도자료 조사 확대와 한계

공식 목록 최상단을 다시 열어 전체1336건, 1/134페이지, 최상단1336번 nttId=12602, 작성일2026-10-29를 관찰했다. 이는 당시 반환 목록의 상태이며 기간 전체 대조 완료가 아니다.

정책브리핑에서 개인정보위 공식 재게시 목록을 확보하여 기존 첫 페이지 10개에 없던 2026-09-23~10-06의 15개 메타데이터·상세 링크를 추가 기록했다. 정부 공식 페이지가 개인정보위 자료임을 표시한다. 원문 동일성을 제목·일자·부처·전재 안내로 확인한 범위와 본문·첨부 확인 범위를 구분한다. 이 15개는 개별 내용 대조 미완료이므로 D이며, 제목만으로 위반·제재를 생성하지 않는다. PIPC 게시물 ID를 정부 재게시 newsId에서 추정하지 않았다.

정책브리핑의 페이지 이동은 웹 도구에서 같은 목록으로 돌아왔고, 실제 상세 링크에서 관찰한 startDate/endDate/pageIndex를 사용한 대상 기간 조회는 접근 불가였다. 브라우저의 정상 공식 목록 탐색도 upstream 연결 시간 초과였다. 동일 경로 재시도와 보안 우회는 중단했다. 따라서 대상 기간 전체 목록은 여전히 미확보이며 전수 최신화 완료 문구를 게시하지 않는다.
