공통 홈에서 세 번째 카드 **AI 해킹 예방 점검 시작하기**를 선택하면 기업·기관용 자가점검 도구가 열립니다. 34개 문항은 고유 ID로 보도자료 근거, 이행 판단 기준, 증적 예시, 개선조치와 연결됩니다. 원문과 문항을 대조하려면 [34문항 전체 및 근거 매핑표](ai-hacking-source-mapping.md)를 참조하세요.

## 로컬에서 열기

전체 소스 ZIP을 압축 해제한 뒤 `package.json`이 있는 폴더에서 실행합니다. 프로젝트의 Node.js 요구 버전은 22.13.0 이상입니다. 이번 검증에는 Node.js 24.22.3, npm 11.19.1과 프로젝트의 잠금 파일을 사용했습니다.

```bash
npm ci
npm run build
npm run start -- --hostname 127.0.0.1
```

공통 홈은 `http://127.0.0.1:3000/`, 신규 화면은 `http://127.0.0.1:3000/ai-hacking`입니다. 서버를 종료할 때는 실행 창에서 Ctrl+C를 누릅니다. 개발 중 변경사항을 즉시 보려면 빌드·시작 명령 대신 `npm run dev -- --hostname 127.0.0.1`을 사용할 수 있습니다.

ZIP의 별도 폴더 `review/`에는 가상 응답을 담은 `sample-result.json`과 해당 결과의 `ai-hacking-sample-report.pdf`가 있습니다. 신규 화면에서 **저장 파일 복원**으로 예시 JSON을 열면 이 보고서의 검증 시나리오를 직접 확인할 수 있습니다.

## 판정과 개선 우선순위

| 응답 | 적용 수 | 진행률 분자 | 이행률 분자 | 결과에서의 처리 |
|---|---:|---:|---:|---|
| 이행 | 포함 | 포함 | 포함 | 이행 건수에 집계 |
| 미이행 | 포함 | 포함 | 제외 | 항목별 개선조치 제시 |
| 확인 필요 | 포함 | 포함 | 제외 | 먼저 확인할 사항과 미이행으로 확인될 때의 조치 제시 |
| 점검 전 | 포함 | 제외 | 제외 | 미응답으로 표시 |
| 해당 없음 | 제외 | 제외 | 제외 | 자동 제외 근거 또는 사용자가 기록한 사유 표시 |

진행률은 응답한 적용 문항 수를 적용 문항 수로 나눈 비율입니다. 이행률은 이행 문항 수를 같은 분모로 나눈 비율입니다. 화면에는 정수로 반올림해 표시합니다. 적용 문항이 0개이면 두 비율을 ‘산정 대상 없음’으로 표시합니다. 수동 제외 사유 입력은 선택이며 비워 두면 ‘사유 미기록’으로 표시합니다.

기본정보가 ‘확인 필요’인 기술은 적용 대상으로 남깁니다. ‘미사용’은 연결된 문항에만 적용하며, 중첩되는 제외 조건은 한 문항으로 계산합니다. 기본정보가 바뀌어 자동 제외될 때도 이전의 직접 응답은 보관합니다. 기관 전체·서비스와 같이 *점검 대상 자체*를 바꾸어 새로 평가할 때는 기존 결과 파일을 보관하고 새 점검을 시작할 수 있습니다.

권고 목록은 긴급, 높음, 보통 순서입니다. 같은 우선순위 안에서는 미이행, 확인 필요, 문항 ID 순으로 표시합니다. 패치 미적용, DB 관리도구 노출·과도한 전체 조회권한, 대량조회·반출 통제 미흡 등을 긴급으로 구성했습니다. 각 등급은 보완 순서를 정하는 실무 기준입니다. 법 위반 여부와 침해 발생 확률의 판정에는 쓰지 않습니다.

## 근거자료 편집 기준

- 개인정보위의 2026년 10월 19일·22일, 11월 18일 보도자료 본문을 첨부 MD 및 공식 게시물과 대조했습니다. S1의 개인 대상 보호수칙, 신고 안내, 내용이 생략된 포스터·표는 문항 근거에서 제외했습니다.
- G-02는 내장 Java 점검과 수탁업체 운영 시스템의 기록 점검을 연결한 실무 확장입니다. 다른 DB 관리 경로까지 적용한 E-04를 비롯해 보도자료보다 범위가 넓어진 부분은 문항의 ‘실무 보완’에 명시했습니다. 접속기록의 보존기간이나 증적 제출 의무는 설정하지 않았습니다.
- Java4Shell(CVE-2026-114938 등)과 PHP2Shell 명칭은 첨부 본문을 따랐습니다. KISA 및 공급자 공지에서 적용 범위와 패치 사례를 확인했고, 소프트웨어 명칭만으로 취약하다고 판단하는 로직은 두지 않았습니다. 공지별 확인 결과와 원문 링크는 매핑표의 ‘기술 공지 대조 기록’에 있습니다.
