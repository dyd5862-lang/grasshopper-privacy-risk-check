## 접근 장애와 정상 경로 시도

- 공식 목록의 실제 2페이지 링크는 `selectBoardList.do?pageIndex=2`로 열리며 게시판 식별정보가 없는 오류 화면을 반환했다. 관찰한 pageIndex를 유지하고 bbsId·mCode를 함께 보낸 정상 목록 요청도 웹 도구에서 접근 불가였다. www 호스트도 실패했다. 기간 검색 폼·JavaScript의 실제 매개변수는 브라우저가 열리지 않아 확인하지 못했다. 임의 API나 첨부 URL은 만들지 않았다.
- 결정문 목록은 정상적인 page=2~6으로 열렸다. 상세 링크에서 따라간 다운로드 버튼은 같은 HTML 상세 페이지를 반환하여 PDF/HWP 본문을 확보하지 못했다. 이는 자료가 비공개라는 뜻이 아니다.
- Vercel의 기존 프로젝트에서 일회성 Sandbox로 공개 목록 URL에 일반 curl 요청을 보냈다. HTTP400 및 `Request Blocked`가 반환되어 중단했다. 보안·인증 우회는 수행하지 않았고 세션은 37.6초 후 종료했다. 기존 프로젝트·운영 배포·환경변수를 변경하지 않았다.
- 기존의 로컬 HTTP503·브라우저 연결 시간 초과 기록은 종전 progress 문서에 보존했다. 이번 웹 도구의 `Internal Error/not accessible`는 원 서버 HTTP 상태 코드로 단정하지 않는다.

접근 실패 기록의 checked_at은 해당 조사 결과의 기록 시각(UTC)이며 개별 네트워크 요청의 정밀 타임스탬프가 아니다. KST 변환과 기준일은 audit-scope.json을 참조한다. 본문 위치는 이번 HTML 텍스트의 줄 번호와 문단명을 병기했으며 사이트 변경 시 줄 번호는 달라질 수 있다.
