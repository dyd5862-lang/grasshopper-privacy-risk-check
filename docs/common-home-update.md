# 공통 시작 화면 개편

기준 커밋: 91b2cd1 (main). 코드 수정과 검증을 완료한 후 사용자의 별도 배포 요청에 따라 운영 반영.

- `/`: 두 도구를 선택하는 공통 시작 화면, 공통 안내·개인정보 입력 주의사항 및 화면 설정.
- `/risk`: 기존 위험도 분석 UI를 그대로 이동. 기존 저장 키, 응답·증적·판정·보고서 로직 유지.
- `/safeguards`: 기존 안전성 확보조치 도구 유지.
- 두 도구의 선택 메뉴에 공통 첫 화면 복귀 경로 추가. 도구 선택의 01/02 표시는 제거.
- 기존 `/#about-risk` 주소는 `/risk#about-risk`로 연결.
- 공통 화면은 점검 데이터를 읽거나 쓰지 않으며 화면 설정만 기존 설정 키를 공유.

## 검증

- ESLint, TypeScript, Next.js production build 통과.
- 기존 자동검사 51개 및 변경한 경로·제목에 대한 HTML 검사 2개 통과.
- Chromium에서 1440px PC 카드 높이·가로 배치, 390px/320px 모바일 세로 배치 및 가로 넘침 없음 확인.
- 공통 메뉴, 두 시작 버튼, 각 도구 복귀 링크 및 테마 전환 확인.
- 두 도구에 서로 다른 시험용 기관명·응답 입력 후 홈 경유 이동 시 데이터 복원 및 저장 키 분리 확인.
- 두 도구의 결과 화면, JSON 다운로드, 초기화 및 다른 도구 데이터 보존 확인.
- 인쇄 버튼의 window.print 호출 및 위험도 분석 인쇄 전용 보고서 표시 확인. 운영체제 인쇄 대화상자/실제 프린터 출력은 미검증.
- 브라우저 pageerror 없음.

최신 저장소에서 언어 전환 및 방문자 집계 구현은 확인되지 않음. 새 기능을 임의로 추가하지 않음.
스크린샷은 로컬 production build에서 촬영했으며, 촬영 환경에 한국어 폰트가 없어 테스트 브라우저에만 Noto Sans KR을 로드함. 제품 코드의 폰트 설정은 유지.
