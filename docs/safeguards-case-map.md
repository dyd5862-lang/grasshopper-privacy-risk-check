# 안전성 확보조치 문항–사례 대응표

검토일: 2026-09-20. 기준: 2025-9호 / 안내서 2025.11 / 대응표 1.0 (2026-09-18).

이 문서는 scripts/generate-safeguards-case-map.mjs로 연결 데이터에서 생성합니다. 사례 본문과 공식 URL은 기존 공통 데이터에서 가져옵니다. 자동 키워드 연결은 하지 않습니다.

## 범위와 한계

- 기존 사례 109건, 의결서 연결 72건(31개 사례).
- 이번 연결: 32/142개 점검 문항, 중복 제외 6개 사례, 43개 연결(직접 29, 참고 14). 사전확인 15개는 사례 연결 대상 점검 문항과 별도입니다.
- 직접 관련은 공식 보도자료에서 해당 보호조치의 실패가 확인된 경우입니다. 현행 세부 조항이 처분 당시 그대로 적용되었다는 뜻이 아닙니다. 계획 수록 여부, 공공시스템 추가의무, 부록의 별도 평가조건은 사실이 확인되지 않으면 참고로만 연결합니다.
- 보도자료 6개 본문 확인. 공개 의결서 12개 기존 연결 중 PDF 12개는 접근 오류로 본문 미검증. 공식 게시판 6개 중 4개에서 7개 의결서의 첨부 존재·의결번호·게시판 의결일 확인, 이 중 5개는 첨부명에서 기관명도 대조. 나머지 2개 게시판(5개 문서)은 접근 오류. 본문 사실관계까지 검증된 의결서는 0개입니다.
- 명품브랜드 사례의 의결서는 기존 자료에서 미확보이며 공개 여부를 확정하지 않습니다. PDF 접근 오류는 비공개나 자료 부재를 뜻하지 않습니다.
- 당시 세부 법조항·고시 버전은 원문 미확인으로 남깁니다. 기존 사례의 laws 필드를 당시 확정 조문으로 표시하지 않습니다.
- 보도자료 날짜는 게시일로, 회의일은 보도자료에서 확인한 의결일로 구분합니다. 공무원연금공단 의결번호에는 2025가 포함되지만 공식 게시판 의결일은 2026-03-25입니다. 이를 임의로 수정하지 않습니다.
- 이번 범위 밖 기존 103개 사례와 그 링크는 전수 재검증하지 않았습니다. 연결 없음은 선례·의무·위험 없음이 아닙니다.
